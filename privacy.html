Privacy Policy

Rosebranch Studio tools. Last updated 25 October 2026.

Who runs it

Rosebranch Studio tools is operated by Rosebranch Studio (Rafael Ramos Rosa). Contact: rosa.rafael.ramos@gmail.com.

Who uses it

Only the owner, on the studio's own YouTube channels and the owner's own Google account. The tool is not offered to the public.

Google data it accesses

  • YouTube Data API: uploads and manages videos, thumbnails, captions and metadata on the owner's channels, and reads their status.
  • YouTube Analytics API: reads reports of the owner's channels.
  • Gmail API (send only): sends notification emails to the owner. It does not read, store or delete any email.

How the data is used

Only to publish and follow the studio's own videos. The data is not sold, not shared with anyone for their own use, and not used for advertising. Analytics of the owner's channels may be processed by an AI service the owner uses (Anthropic's Claude) to prepare internal reports for the owner. Google user data is not used to develop, improve or train generalized AI or machine learning models.

The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Where it is stored

Access tokens are kept in the Windows Credential Manager of the owner's computer. Reports are kept on that computer's disk. The tool has no server of its own.

Keeping and deleting data

Data is kept while it is needed to run the channels. Access can be revoked at any time at myaccount.google.com/permissions; the tokens are then deleted from the owner's computer.

YouTube API Services

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Access granted to the tool can also be revoked from the Google security settings page.

Changes

Changes to this policy are posted on this page with a new date.
